# Rakesh Soni · Solar System 3D Portfolio

An interactive, immersive 3D Solar System personal portfolio for **Rakesh Soni** (Full-Stack & Systems Software Engineer), built with **React**, **Three.js / WebGL**, and **Tailwind CSS**.

Inspired by the clean editorial aesthetics of [arstraumur.music](https://arstraumur.music/) combined with a real-time astronomical 3D journey through our solar system.

---

## 🌌 Features

- **Dynamic 3D Solar System Journey**:
  - Physically-scaled sun with animated procedural solar flares, turbulence noise shader, and golden corona radiance.
  - Realistic planetary orbits (Mercury, Venus, Earth with orbiting Moon, Mars, Jupiter with Great Red Spot, Saturn with rings, Uranus, Neptune).
  - Cinematic scroll-bound camera choreography (fly-throughs, 360°/180° rotations, smooth zoom in/out).
  - Deep cosmic starfield with 6,000+ depth-mapped stars and volumetric nebula cosmic dust clouds.
- **Editorial Monochrome & Celestial Design**:
  - High-end typography (Marcellus serif headers, Inter body text).
  - Clean individual achievement and project displays with live links and modals.
  - Large authentic signature hero section.

- **Styling**: Tailwind CSS + Custom CSS Variables
- **Icons**: Lucide React
- **Fonts**: Marcellus & Inter via Google Fonts

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm / pnpm / yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/rakeshsoniiii/portfolio.git

# Navigate to project directory
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173` to explore the experience.

### Production Build
```bash
npm run build
npm run preview
```
